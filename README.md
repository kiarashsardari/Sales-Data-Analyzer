# Sales-Data-Analyzer
تحلیل فروش:

این پروژه یک ابزار ساده برای تولید و تحلیل داده های فروش است
با اجرای برنامه یک مجموعه داده مصنوعی از فروش کالاها ساخته می شود و سپس شاخص های آماری مهم روی آن محاسبه و نمایش داده می شود

ساختار پروژه:

پروژه از سه فایل پایتون تشکیل شده است:

فایل dataset_maker.py:

این فایل مجموعه داده فروش را می سازد
محصولات و قیمت پایه آن ها در یک دیکشنری تعریف شده اند
تعداد 100 تراکنش به صورت تصادفی تولید می شود
برای هر تراکنش محصول تعداد فروش و تاریخ به صورت تصادفی انتخاب می شوند
قیمت کل هر تراکنش از ضرب قیمت پایه در تعداد فروش به دست می آید
داده ها در فایل Sales_Data.csv ذخیره می شوند

فایل calculate.py:

این فایل شامل توابع تحلیل و رسم نمودار است

تابع summary:
برای هر ماه مجموع قیمت فروش را محاسبه و چاپ می کند

تابع best_product:
محصولی که بیشترین مجموع فروش را داشته است پیدا می کند و چاپ می کند
اگر چند محصول بیشترین فروش را داشته باشند همه آن ها چاپ می شوند

تابع vector:
نمودار خطی مجموع فروش را بر حسب تاریخ رسم می کند

تابع main:
تابع summary را اجرا می کند
سپس با فشردن کلید Enter تابع best_product را اجرا می کند
و در نهایت با فشردن مجدد Enter تابع vector را اجرا می کند

فایل run.py:

این فایل نقطه شروع اجرای برنامه است
ابتدا تلاش می کند فایل داده را بخواند
اگر فایل وجود نداشته باشد آن را می سازد و سپس تحلیل را انجام می دهد

نحوه اجرا:

برای اجرای برنامه دستور زیر را در ترمینال وارد کنید

python run.py

اگر فایل داده از قبل وجود داشته باشد فقط تحلیل انجام می شود
در غیر این صورت ابتدا داده ساخته شده و سپس تحلیل صورت می گیرد

پیش نیازها:

برای اجرای این پروژه به کتابخانه های زیر نیاز دارید

numpy
pandas
matplotlib

می توانید آن ها را با دستور زیر نصب کنید

pip install numpy pandas matplotlib

خروجی برنامه:

پس از اجرا ابتدا مجموع فروش هر ماه در ترمینال نمایش داده می شود
سپس با فشردن کلید Enter بهترین محصول یا محصولات از نظر فروش چاپ می شوند
در نهایت با فشردن مجدد Enter نمودار خطی فروش نمایش داده می شود

نکته:

داده های تولید شده کاملا تصادفی هستند و صرفا برای تمرین و آزمایش کد استفاده می شوند
این داده ها بیانگر فروش واقعی هیچ کسب و کاری نیستند
